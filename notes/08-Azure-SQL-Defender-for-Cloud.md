# Microsoft Defender for Cloud for Azure SQL

## Overview

Microsoft Defender for Cloud provides security capabilities for protecting cloud resources, including databases.

For Azure SQL, Defender for Cloud can provide additional threat protection and security monitoring capabilities.

It complements other security controls such as:

- Microsoft Entra ID
- RBAC
- Firewall
- Private Endpoint
- Auditing
- Encryption
- TLS

---

# Why Defender for Cloud Is Important

Traditional security controls help prevent unauthorized access.

However, organizations also need to detect suspicious or malicious activity.

Defender for Cloud adds an additional security layer for threat detection.
